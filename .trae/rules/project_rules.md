# PPT 风格规范

当使用 pptx skill 生成 PPT 时，必须严格遵循以下风格规范：

## 整体风格

深色科技风（Dark Tech / Ocean Gradient）——深海军蓝背景 + 青绿色强调色，高端、专业、技术感。

## 色彩体系

| 角色 | 色值 | 用途 |
|------|------|------|
| 主背景 | `#0F172A` | 所有幻灯片统一深海军蓝纯色背景 |
| 卡片背景 | `#1E3A5F` | 圆角卡片、信息块填充 |
| 主强调色 | `#02C39A` (薄荷绿) | 章节编号、左侧竖条、标题下划线、关键词高亮 |
| 次强调色 | `#06B6D4` (青色) | 第三章节编号/竖条等辅助强调 |
| 第三强调色 | `#F59E0B` (琥珀黄) | 第四章节编号/竖条等警示/重点强调 |
| 辅助色 | `#1C7293` (深青蓝) | 左侧窄竖条装饰、半透明叠加层 |
| 主文字 | `#FFFFFF` | 标题、正文 |
| 副文字 | `#94A3B8` (灰蓝) | 描述文字、卡片内说明 |
| 页脚文字 | `#64748B` (暗灰蓝) | 页码、部门信息、日期 |

## 布局特征

- **左侧装饰条**：极窄的薄荷绿 + 深青蓝双竖条（约2px+1px），贯穿整页左侧边缘
- **圆角卡片**：圆角矩形（roundRect），深蓝填充 `#1E3A5F`，带底部柔和阴影（25%透明度黑色外阴影）
- **卡片内竖条**：左侧4px薄荷绿竖条标识
- **标题下划线**：薄荷绿半透明（60-70%透明度）细横线
- **页码**：右下角，灰蓝色小字（9pt），格式 `X / N`

## 字体规范

- **全局字体**：Calibri（中文/英文统一）
- **封面标题**：40pt，加粗，白色
- **章节编号**：32-72pt，加粗，强调色
- **页面标题**：24pt，加粗，白色
- **正文**：13-16pt，白色或灰蓝色
- **描述/副标题**：11-13pt，灰蓝色 `#94A3B8`
- **页码**：9pt，灰蓝色 `#64748B`

## 幻灯片类型模板

### 封面页
- 全页深海军蓝背景 `#0F172A`
- 左侧薄荷绿+深青蓝双竖条装饰
- 大标题白色40pt加粗，标题下方薄荷绿半透明横线
- 副标题/部门信息灰蓝色14pt
- 日期灰蓝色13pt
- 右上角装饰图标（85%透明度）

### 目录页
- 深海军蓝背景
- 页面标题白色32pt加粗 + 薄荷绿下划线
- 4个圆角卡片纵向排列，每个卡片包含：
  - 深蓝填充 `#1E3A5F` + 底部阴影
  - 左侧薄荷绿竖条标识
  - 章节编号（薄荷绿32pt加粗）
  - 图标
  - 标题（白色20pt加粗）
  - 描述（灰蓝色11pt）
- 不同章节使用不同强调色竖条：01薄荷绿、02薄荷绿、03青色、04琥珀黄

### 章节分隔页
- 全页半透明深青蓝叠加（15-25%透明度 `#1C7293`）
- 左侧大号章节编号（72pt，强调色）
- 白色标题（36pt加粗）
- 灰蓝色副标题（16pt）
- 右侧装饰图标

### 内容页
- 深海军蓝背景
- 左侧双竖条装饰
- 页面标题薄荷绿24pt加粗 + 半透明薄荷绿下划线
- 内容区域使用圆角卡片（`#1E3A5F`）承载
- 关键信息用强调色高亮
- 右下角页码

### 结尾页
- 深海军蓝背景
- 居中"感谢聆听"白色大字
- 部门/年份信息灰蓝色
